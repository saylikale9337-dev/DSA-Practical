## Algorithm
1.Start.
2.Initialize head = NULL and tail = NULL.
3.Display the menu of operations.
4.Accept the user's choice.
5.If the choice is Add Task, create a new node and insert it at the end.
6.If the choice is Display Forward, display all tasks from head to tail.
7.If the choice is Display Backward, display all tasks from tail to head.
8.If the choice is Search Task, search using Task ID.
9.If the choice is Delete Task, delete the specified task.
10.If the choice is Count Tasks, count and display the total tasks.
11.Repeat until the user selects Exit.
12.Stop.
