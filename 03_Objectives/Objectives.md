Objective: 
1. To understand the implementation of a Singly Linked List.
2. To perform insertion, deletion, searching, and traversal operations.
3. To manage space mission tasks efficiently using dynamic memory allocation.
4. To demonstrate real-world applications of linked lists in mission planning and task scheduling.

Objectives for Double linked list:
1.To understand the concept of a Doubly Linked List.
2.To perform insertion and deletion operations.
3.To traverse the list in forward and backward directions.
4.To search tasks using Task ID.
5.To count the total number of tasks.

Objectives for Circular linked list
1. To understand the concept of a Circular Linked List.
2. To perform insertion and deletion operations.
3. To traverse the list circularly.
4. To search for a task using Task ID.
5. To count the total number of tasks.
