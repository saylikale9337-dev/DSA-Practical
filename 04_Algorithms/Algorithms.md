Step 1: Start the program.

Step 2: Create an empty linked list.

Step 3: Display menu options:

Add Task

Delete Task

Search Task

Update Task Status

Display Tasks

Count Tasks

Exit

Step 4: Accept user's choice.

Step 5: Perform corresponding operation:

Insert a new task.

Delete a task using Task ID.

Search a task using Task ID.

Update task status.

Display all tasks.

Count total tasks.

Step 6: Repeat Steps 3 to 5 until Exit is selected.

Step 7:Stop the program.



Algorithm for Double Linked list:
1.Start.
2.Initialize head = NULL and tail = NULL.
3.Display the menu of operations.
4.Accept the user's choice.
5.If the choice is Add Task, create a new node and insert it at the end.
6.If the choice is Display Forward, display all tasks from head to tail.
7.If the choice is Display Backward, display all tasks from tail to head.
8.If the choice is Search Task, search using Task ID.
9.If the choice is Delete Task, delete the specified task.
10.If the choice is Count Tasks, count and display the total tasks.
11.Repeat until the user selects Exit.
12.Stop.


 Algorithm for Circular Linked list-
1.Start.
2.Initialize head = NULL.
3.Display the menu of operations.
4.Accept the user's choice.
5.If the choice is Add Task, create a new node and insert it at the end.
6.If the choice is Display Tasks, traverse the list until the head is reached again.
7.If the choice is Search Task, search using Task ID.
8.If the choice is Delete Task, remove the specified node and maintain the circular link.
9.If the choice is Count Tasks, count and display the total number of tasks.
Repeat until the user selects Exit.
10.Stop.
