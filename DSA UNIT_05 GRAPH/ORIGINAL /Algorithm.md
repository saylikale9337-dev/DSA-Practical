## Algorithm 
1.Start the program.
2.Create a weighted graph using an adjacency list.
3.Accept the number of routers and communication links.
4.Enter the source and destination routers with the cost of each link.
5.Accept the source router.
6.Initialize the distance of the source router to 0 and all other routers to infinity.
7.Select the unvisited router with the minimum distance.
8.Update the distances of its adjacent routers if a shorter path is found.
9.Repeat until all reachable routers are processed.
10.Display the minimum cost from the source to each router.
11.Accept the destination router.
12.Trace the previous-router information to reconstruct the shortest path.
13..Display the shortest router sequence and its total cost.
14.Stop the program.
