## Objective
1. To represent a communication network using a weighted graph.
2. To implement Dijkstra's shortest path algorithm.
3. To calculate minimum link costs from a selected source router.
4. To display the complete shortest path to a destination router.
5. To allow the user to select a different source router and recalculate shortest distances.
6. To update an edge weight and recalculate shortest paths.
7. To understand the application of graphs in computer networks.
