## Algorithm
1.Start the program.
2.Accept the number of routers and communication links.
3.Create a weighted graph using an adjacency list.
4.Enter the source and destination routers with the cost of each communication link.
5.Select a source router.
6.Initialize the source distance to 0 and all other distances to infinity.
7.Apply Dijkstra's algorithm to calculate minimum distances.
8.Display the minimum link costs from the selected source.
9.Select a destination router and reconstruct the shortest path using the parent array.
10.Display the complete shortest path and its total cost.
11.Allow the user to select a different source router and recalculate the shortest distances.
12.Allow the user to update the weight of an existing communication link.
13.Run Dijkstra's algorithm again using the updated graph.
14.Display the updated minimum distances and shortest path.
15.Stop the program.
