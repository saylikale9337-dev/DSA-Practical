Design and implement a Space Mission Task Management System using a Singly Linked List. Each task in the mission contains Task ID, Task Name, Priority Level, and Task Status. The system should allow users to add new tasks, delete existing tasks, search for tasks, update task status, display all tasks, and count the total number of tasks. The linked list should dynamically manage mission tasks during different phases of a space mission.

Problem Statement for Double linked list--
To develop a Space Mission Task Management System using a Doubly Linked List in C++. The system stores 
task details such as Task ID, Task Name, Priority and Status. It allows users to add, display, search 
and delete tasks. It also supports forward and backward traversal of the linked list.

Problem Statement for Circular linked list--
To develop a Space Mission Task Management System using a Circular Linked List in C++. The system 
stores mission task details and allows users to add, display, search and delete tasks. The 
last node points to the first node, forming a circular structure.
